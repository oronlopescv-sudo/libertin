PASSO A PASSO NO HOSTINGER (só a tua parte, ~2 minutos)
-------------------------------------------------------
1. Painel Hostinger → Websites → (xlibertine) → Deployment / Build settings
2. Abre "Variables d'environnement"
3. Cola lá estas duas linhas (são PÚBLICAS — sem segredo):

   NEXT_PUBLIC_SUPABASE_URL=https://mfchfnsekoluicxnguoh.supabase.co
   NEXT_PUBLIC_APP_URL=https://xlibertine.com

4. Cola também (um por chave, valores reais desta máquina):

   NEXT_PUBLIC_SUPABASE_ANON_KEY  ← no env.example/terminal (ver dump abaixo)
   SUPABASE_SERVICE_ROLE_KEY     ← a chave LEGACY (formato eyJ..., NÃO a sb_...)
   STRIPE_SECRET_KEY             ← a rk_live_... do .env.production
   STRIPE_WEBHOOK_SECRET         ← o whsec_... do webhook criado na Stripe
   STRIPE_LINK_PASS_EPICURIEN    ← o buy.stripe.com/... Épicurien (9€/mês)
   STRIPE_LINK_PASS_PRIVILEGE    ← o buy.stripe.com/... Privilège (15€/mês)
   STRIPE_LINK_PASS_VIP          ← o buy.stripe.com/... VIP Elite (25€/mês)

5. Guardar e clicar DEPLOY. Espera o build terminar (verde).

DUMP DOS VALORES DA TUA MÁQUINA (escrever na caixa de texto daqui)
------------------------------------------------------------------
! cat /root/libertin/.env.production

Nota: o SUPABASE_SERVICE_ROLE_KEY que lá está está no formato NOVO (sb_...,
não aceito pelo Storage). Vai ao Supabase (Settings → API Keys → Legacy API
keys) e copia a service_role em formato eyJ....
